OVER HET PROJECT

Dark Tech

Voor dit project onderzoeken we de ethische gevolgen van technologie. Ons concept is een AI-companion voor kinderen, in de vorm van een teddybeer. We onderzoeken hoe deze technologie kinderen kan ondersteunen, maar ook welke ongewenste gevolgen kunnen ontstaan.
